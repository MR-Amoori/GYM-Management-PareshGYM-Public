# GYM-Management-PareshGYM

## 🇺🇸 English

### 📖 About The Project
This project is a Windows Forms application built with **C#** and **.NET Framework 4.6.2**. It acts as a desktop wrapper for the ClubPro web panel using **CefSharp** (Chromium Embedded Framework). It is specifically optimized to run smoothly on legacy systems, including **Windows 7 (32-bit)**.

### ✨ Features
- **Legacy Support:** Fully compatible with Windows 7 (x86) architectures.
- **Automated Login:** Uses JavaScript injection to bypass manual login steps and auto-fill credentials.
- **Custom Web Engine:** Utilizes CefSharp (v109.1.110) for robust DOM manipulation and seamless navigation control.
- **UI Overlay:** Custom loading screens to hide web transitions from the end user.

### 🛠️ Built With
- [C#](https://docs.microsoft.com/en-us/dotnet/csharp/)
- [.NET Framework 4.6.2](https://dotnet.microsoft.com/)
- [CefSharp.WinForms (v109.1.110)](https://github.com/cefsharp/CefSharp)

### 🚀 Getting Started
#### Prerequisites
- .NET Framework 4.6.2
- Visual C++ Redistributable 2015-2022 (x86)

#### Installation
1. Clone the repo:
   ```sh
   git clone https://github.com/MR-Amoori/Paresh-GYM-Management-System.git
   ```
2. Build the project in Visual Studio (Ensure Platform Target is set to **x86**).
3. Create a `credentials.txt` file in the build directory with your local app login data:
   ```text
   username=admin
   password=123
   ```
4. Run the executable.

## 🇮🇷 فارسی

### 📖 درباره پروژه
این پروژه یک اپلیکیشن ویندوز فرم (Windows Forms) است که با **C#** و **.NET Framework 4.6.2** نوشته شده است. این برنامه به عنوان یک پوسته دسکتاپ برای پنل وب ClubPro عمل می‌کند و از موتور **CefSharp** بهره می‌برد. این نرم‌افزار به صورت ویژه برای اجرای پایدار روی سیستم‌های قدیمی از جمله **ویندوز ۷ (۳۲ بیتی)** بهینه‌سازی شده است.

### ✨ امکانات
- **پشتیبانی از سیستم‌های قدیمی:** سازگاری کامل با معماری ۳۲ بیتی (x86) و ویندوز ۷.
- **ورود خودکار (Auto-Login):** استفاده از تزریق جاوااسکریپت (JS Injection) برای پر کردن خودکار فرم‌های لاگین وب‌سایت.
- **موتور وب قدرتمند:** استفاده از CefSharp نسخه 109.1.110 جهت دستکاری دقیق DOM و کنترل مسیرها.
- **پوشش لودینگ:** دارای صفحات بارگذاری اختصاصی برای پنهان کردن پرش‌های صفحات وب از دید کاربر.

### 🛠️ تکنولوژی‌ها
- C#
- .NET Framework 4.6.2
- CefSharp.WinForms (نسخه 109.1.110)
